# Моё меню — Telegram Mini App (Стол № 5)

Стартовый проект на Nuxt 3 + Vue 3 + JavaScript. Это frontend без сервера и без ИИ.

## Что есть

- меню на 7 дней;
- карточки рецептов с ингредиентами, шагами и режимами мультиварки;
- поиск рецептов по названию и ингредиентам;
- избранное;
- список покупок с отметками;
- сохранение отметок и избранного в `localStorage` этого браузера;
- базовая интеграция с Telegram Web Apps API.

## Важно о данных

Это технический прототип, а не проверенная лечебная диета. Калорийность блюд приблизительная, меню и список покупок могут требовать пересчёта по реальным порциям. Не используй приложение как медицинское назначение без проверки меню специалистом.

## 1. Требования

- Node.js LTS (рекомендуется актуальная версия LTS);
- npm;
- аккаунт GitHub для публикации через Git;
- Telegram и доступ к `@BotFather`.

Проверить установку:

```bash
node -v
npm -v
```

## 2. Запуск на Windows

Распакуй ZIP, открой папку проекта в WebStorm или Cursor и выполни в терминале:

```bash
npm install
npm run dev
```

Открой адрес, который напечатает Nuxt (обычно `http://localhost:3000`). В обычном браузере приложение работает как веб-сайт; интеграция Telegram активируется внутри Telegram.

## 3. Создание Telegram-бота

1. Открой `@BotFather` в Telegram.
2. Отправь `/newbot` и следуй инструкциям.
3. Сохрани токен в безопасном месте. Для этого прототипа токен не нужен и в frontend его добавлять нельзя.
4. Сначала опубликуй сайт на HTTPS, затем в BotFather настрой Mini App / Main App для созданного бота и укажи публичный URL.
5. Открой ссылку бота в Telegram и проверь интерфейс на телефоне.

Названия пунктов BotFather могут меняться. Официальная документация Telegram: https://core.telegram.org/bots/webapps

## 4. Бесплатная публикация на Cloudflare Pages

Самый понятный путь — GitHub + Cloudflare Pages.

1. Создай пустой репозиторий на GitHub.
2. Загрузи туда файлы проекта.
3. В Cloudflare Dashboard открой Workers & Pages и создай Pages-проект из Git-репозитория.
4. Для этого проекта задай:
   - Build command: `npm run generate`
   - Build output directory: `.output/public`
5. Запусти публикацию и дождись HTTPS-адреса `*.pages.dev`.
6. Привяжи этот URL к Mini App в BotFather.

Проверяй текущие настройки в официальной документации Cloudflare:  
https://developers.cloudflare.com/pages/framework-guides/deploy-a-nuxt-site/

Если выбранный шаблон Cloudflare предлагает другой способ создания Nuxt-проекта, не смешивай его конфигурацию с этим проектом без проверки.

## 5. Как вносить изменения

- Рецепты и недельное меню: `data/menu.js`
- Интерфейс и навигация: `pages/index.vue`
- Стили: `assets/css/main.css`
- Настройки Nuxt: `nuxt.config.ts`

После изменения `data/menu.js` проверь, что IDs в `weekPlan.meals` совпадают с `recipes[].id`.

## Ограничения прототипа

- Нет серверной базы данных: сохранения находятся локально в браузере/WebView и не синхронизируются между устройствами.
- Нет авторизации на сервере, API и ИИ.
- Не добавляй секреты и токен Telegram в клиентский код.
- Если позже добавится сервер, проверяй `Telegram.WebApp.initData` на сервере; не доверяй `initDataUnsafe`. Официальная инструкция: https://core.telegram.org/bots/webapps#validating-data-received-via-the-mini-app
- Бесплатные условия хостинга могут меняться; перед публикацией проверь актуальные лимиты и условия поставщика.
