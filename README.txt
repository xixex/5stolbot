# Замена файлов для Stol5 Mini App

В архиве находятся два файла для замены:
- `data/menu.js` — 32 рецепта, меню на 4 недели, 4 отдельных списка покупок.
- `pages/index.vue` — переключение недель/дней, отдельный список покупок для каждой недели.

## Как применить
1. В GitHub открой `data/menu.js` → Edit → замени содержимое файлом из архива → Commit changes.
2. Открой `pages/index.vue` → Edit → замени содержимое файлом из архива → Commit changes.
3. После каждого коммита GitHub Actions автоматически запустит публикацию.
4. Проверь вкладку Actions и открой https://xixex.github.io/5stolbot/ после зелёной галочки.

## Важно
Меню — пример для дальнейшей проверки, не индивидуальное медицинское назначение. Значения калорийности приблизительны; списки покупок округлены для удобства и могут требовать корректировки по фактическим порциям и запасам дома. План включает три основных приёма пищи в день, без отдельных перекусов.
